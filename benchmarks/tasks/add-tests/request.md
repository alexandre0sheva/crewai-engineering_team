# Add tests for `textkit`

The module `textkit/words.py` has no tests at all. Please add a thorough unit test suite for it:
use the standard library `unittest`, put the tests in a `tests/` directory so that
`python -m unittest discover -s tests` runs them, and cover normal use, edge cases and the
documented error. Do **not** change anything under `textkit/`: the tests must pass against the
module as it is.
