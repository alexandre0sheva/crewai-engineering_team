# Documentation checklist

Your checklist: what it is and who it is for; install, run, and test steps that match the
project's real commands; configuration and environment variables; examples with real output; known
limitations; and a CHANGELOG.md in Keep a Changelog style.

Copy commands from the project's manifests and scripts, run them, and paste the output you saw;
never write an example you did not run.
